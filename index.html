接入指南
  1. 填入服务的 API 地址（需返回 JSON，可含认证）
  2. 选择认证方式并填入 Token（无需认证可跳过）
  3. 点「测试连接」确认返回结构
  4. 按返回的 JSON 层级修改「数据映射」路径，如 data.stats.today、data.items

数据与备份

「应用页面内置配置」会把部署文件 WB_ENV 变量区里的 API 参数覆盖到本设备（含 Token）。API 参数也可直接修改部署文件顶部的 WB_ENV 后重新部署，对所有设备生效。

登录密码在部署文件的 WB_ENV.LOGIN 中修改（PASS_SHA256 = sha256(SALT+新密码)），登录凭据校验仅存于页面内。

手机使用技巧：用浏览器打开本页 → 分享 → 「添加到主屏幕」，即可像 App 一样全屏使用。
